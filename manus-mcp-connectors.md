# MCP Connectors

Connect Manus to your team's tools and enable context-driven creation — moving from idea to validation to live app faster than ever.

## What are MCP Connectors?

MCP Connectors integrate Manus with your existing tools using MCP (Model Context Protocol) servers. By connecting MCP servers, Manus gains the ability to read from and write to the tools your team already uses — triggering workflows, fetching context, and acting across apps in a single task.

## Why Connect MCP Servers

- **Context-aware creation**: Manus pulls live data from your tools to generate outputs that reflect real state — not just prompts.
- **Cross-app automation**: Trigger multi-step workflows spanning multiple services without switching tabs or copying data manually.
- **Faster iteration**: Move from idea to validated, live output by chaining tool actions through a single Manus task.

## How MCP Connectors Work

1. Connect an MCP server to Manus from the Integrations panel.
2. Manus discovers the available tools and resources exposed by that server.
3. When you run a task, Manus selects and invokes the relevant tools automatically based on context.
4. Results are returned to Manus and composed into the final output or used to drive the next step.

## Multi-App Workflow Examples

### Notion + Google Calendar

Pull meeting notes from Notion and schedule follow-up events in Google Calendar based on action items extracted by Manus.

### Gmail + Document Analysis

Read incoming emails from Gmail, extract attachments or linked documents, and produce structured summaries or analyses.

### Stripe + Data Analysis

Fetch transaction data from Stripe and generate revenue reports, cohort breakdowns, or forecasts directly in Manus.

### HubSpot + Gmail + Notion

Sync CRM contacts from HubSpot, draft personalized outreach emails via Gmail, and log activity summaries back to Notion — all in one task.
